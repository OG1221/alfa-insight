## Как продолжить

Прочитать README и docs/verification.md, проверить git status. При остановке сайта: ./scripts/start-local.sh.
В интерфейсе Settings → токен локального администратора из .env (по умолчанию alfa-local-admin) → официальный набор.
Оригиналы и база локальны: data/private, runtime/pgdata. Их не публиковать. Не очищать volume/базу ради повторного запуска.
После выдачи API следовать docs/llm-setup.md; Docker проверять независимо. Основной путь защиты — docs/demo-script.md.
