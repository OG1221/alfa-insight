# Проверка требований

| Требование | Где проверять |
|---|---|
| Контекст компании | Профиль: отрасль, география, продукты, ВЭД, группа, связи и дополнительные признаки |
| Персональная лента | Одна новость для разных компаний и ролей; основания балла в разборе |
| Интерпретация | Последствия, риски, возможности и направления действий |
| Экспертиза банка | Раздел банковских материалов, цитаты, страницы и оригиналы |
| Источники | Вкладка источников, ID доказательств и проверка цитат |
| Новые события | Ввод ранее не показанной новости текстом или разрешённым URL |
| Пользовательский путь | Выбор компании → лента → разбор → источники → вопрос |
| Агентная логика | Журнал: контекст, поиск, оценка достаточности, повторный поиск и проверка |
| Адаптация | Пустая или слабая выдача; пробелы модели и ошибки проверки черновика |
| Трассируемость | План, результаты инструментов и источники сохраняются в PostgreSQL |
| Качество | Метрики, отзывы, регрессионные тесты и процесс разметки в `quality.md` |
| Воспроизводимость | Docker Compose, миграции, lock-файлы, синтетические данные и GitHub Actions |

Без подключённого API генеративная интерпретация и уточняющий диалог не подтверждены. Тестовый провайдер проверяет технический процесс. Рыночная доля и денежное влияние не вычисляются при отсутствии необходимых данных.
