# Матрица 12 критериев

Статусы относятся к фактическому локальному стенду на 25 октября 2026. «Реализовано» не означает полное соответствие при отсутствии настоящей LLM.

| № | Критерий | Механизм и модуль | Демонстрация / проверка | Состояние и ограничения |
|---|---|---|---|---|
| 1 | Бизнес-контекст и отбор | ETL, profiles, ranking, config/ranking.json | Официальные U_9250/U_57706, разные продукты/оценки; тесты профиля и ранжирования | Работает по правилам. Неизвестны денежные единицы, доля рынка и реальные остатки |
| 2 | Содержательная интерпретация | agent.rule_interpretation, GeneratedInsight, Provider | Шесть блоков, условные риски/возможности/проверки, различные интерпретации одного события | Частично: правила проверены; глубокая генеративная интерпретация требует реального API и экспертной оценки |
| 3 | Экспертиза банка | PDF/OCR, Full-Text Search, evidence | Девять реальных PDF, 172 фрагмента, страницы и оригиналы; поиск ставки | Поиск и отображение работают. Смысловая интеграция экспертизы в LLM-выводы не проверена; OCR требует сверки |
| 4 | Источники и факты | RSS, дедуп, ручной ввод, evidence, check_claims | Два реально полученных RSS; source IDs, проверка числовых значений и точных цитат; тест ложной ссылки | Ссылки и происхождение сохранены. RSS может быть анонсом; семантической гарантии нет |
| 5 | Ранее неизвестные новости | POST articles, URL/text, динамические правила и план | Playwright создаёт новую новость и анализирует её; backend интеграционный тест | Технический сценарий работает. Качество настоящей LLM не измерено |
| 6 | Полный пользовательский путь | React → FastAPI → PostgreSQL → agent | Компания → профиль → лента → разбор → новый текст → источники | Работает локально с честным режимом правил. Docker и генеративный контур ещё не проверены |
| 7 | Масштабируемость | PostgreSQL индексы, пакетный ETL, лимиты выдачи | Импорт >1.38 млн платёжных строк, схема и план сопровождения | Практический объём загружен; нет промышленного load test, очереди и многопользовательского SSO |
| 8 | Мониторинг качества | metrics, agent_runs/steps, llm_usage, feedback | Фактические запуски/время/ошибки/резервы/оценки, API metrics | Работает. Precision@K и nDCG оставлены пустыми до обоснованной разметки |
| 9 | Вход с главного экрана | Обзор, hero-action, sidebar, кнопка события | Непосредственный переход к разбору с главной | Работает; конкурсный прототип, не официальный интернет-банк |
| 10 | Интерактивность | Источники, фильтры, смена компании/роли, questions | Рабочая навигация и источники; API question возвращает явную 503 без LLM | Частично: генерируемые уточняющие ответы требуют ключа; не имитируются |
| 11 | Самостоятельная агентная логика | Собственный Python Agent + инструменты + условный план | Журнал, адаптация поиска, пропуск связей, лимиты, тесты сбоев | Реальный оркестратор работает. Автономное изменение плана по смысловой оценке LLM пока не проверено |
| 12 | Трассируемость | Persisted context, evidence, plan, steps, validation | Вкладки источников и фактически исполненных действий, run ID | Работает. Автоматическая проверка ограничена ID, числовыми значениями и точными цитатами, не скрытыми рассуждениями |

Обязательная внешняя зависимость AI: подтверждённый API организаторов. Постоянный публичный сервер требует отдельного размещения. Нельзя объявлять все 12 критериев полностью выполненными до соответствующих проверок.
