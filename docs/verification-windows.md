# Проверка доработанной версии на Windows

Дата: 25 октября 2026, Europe/Moscow. Код, окружение, база, исходный ZIP и рабочие файлы находятся на D:/Codex/alfa-insight-2026-10-25.

## Что изменено

- Контекст агента включает связи, связанные события, конфликты профиля, возраст, категории численности работников и форму организации.
- Оцениваются достаточность и тематическая применимость источников. При нехватке данных выполняется расширенный поиск, после него оценка обновляется.
- Модель может запросить до двух ограниченных текстовых поисков; результаты повторно проверяются перед финальным ответом. SQL, произвольные URL и команды модели недоступны.
- Источники финальных цитат проверяются по действительно переданному контексту. Смысловая поддержка автоматически не гарантируется.
- Вопрос по разбору выполняет поиск, учитывает два предыдущих ответа и показывает свои источники.
- Охват ссылками вычисляется по утверждениям, приватные разборы исключены из демо-метрик.
- CSV читается частями, аудит конфликтов пишется пакетами. CLI возвращает ошибку при неудачном импорте.
- Исправлена загрузка файлов через интерфейс Windows: временный файл закрывается перед импортом; положительный сценарий администратора проверен тестом.
- Windows OCR использует Tesseract rus+eng; macOS-файл не запускается на другой системе. Отчёты сохраняются в UTF-8.
- Миграция 0005 индексирует фильтр доступа к компаниям. Устранена задержка начального списка компаний. Один измеренный локальный запрос после исправления: около 11 мс; это не нагрузочный тест.
- Добавлены Windows-запускатель, инструкции и фиксация переносимых окончаний строк.

## Подтверждено заново

- 54 backend-теста прошли, включая новую пустую схему с миграциями до 0005.
- TypeScript и Vite: сборка прошла.
- 8/8 Playwright desktop/mobile прошли без пропусков. До исправления индекса первый холодный запрос не укладывался в ожидание теста; итоговый прогон выполнен после исправления.
- 85 514 официальных профилей, 12 514 связей и 1 380 584 платежа импортированы. Дополнительно 3 синтетических профиля и 2 платежа.
- 9 банковских PDF, 64 страницы, 179 фрагментов (Tesseract). Разница с прежними 172 фрагментами объясняется другим OCR.
- Одинаковое архивное событие для U_9250 и U_57706 даёт баллы 66 и 59 и разные последствия; в каждом разборе найдены 4 фрагмента банка. Это режим правил.
- RSS Банка России и Интерфакса успешно получены.
- Compose-конфигурация валидна. Повторная сборка и запуск нового образа не подтверждены: в начале проверки хранилище Docker на C: получило ошибку записи. На D: поднят отдельный PostgreSQL без изменения системных служб.

## Что ещё требует внешних действий

Реальный API не выдан. Тестовый провайдер подтверждает технические сценарии, но не смысловое качество разрешённой модели. Для окончательной AI-проверки нужны endpoint, протокол, model ID, ключ и тарифы, затем scripts/check_llm.py --run и экспертная проверка новых событий.

Текущая версия подготовлена для публикации в отдельной ветке GitHub. Состояние CI фиксируется отдельно; доступ alfa-hack-2026 и отправка формы требуют подтверждения. Точный commit указан в manifest архива. Постоянный публичный сервер не настроен; в кейсе это рекомендация, а не обязательный элемент комплекта.

При первоначальном тяжёлом параллельном импорте Windows дважды сообщала ошибки чтения страниц/библиотеки PostgreSQL. База восстановлена, импорт завершён повторно, итоговые проверки выполнены последовательно. Стабильность под промышленной нагрузкой не заявляется.

Precision@K/nDCG и смысловое качество требуют размеченного контрольного набора. План оценки находится в docs/quality.md. Денежное влияние и рыночная доля не выдумываются при отсутствии исходных данных.
