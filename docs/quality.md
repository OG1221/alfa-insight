# Оценка качества

## Технические показатели

В разделе «Качество и источники» доступны количество запусков, ошибки, длительность, охват ссылками, отзывы и стоимость LLM. План и результаты инструментов сохраняются для каждого разбора.

Охват ссылками показывает долю утверждений с существующими ID доказательств. Он не оценивает смысловую корректность.

## Персонализация

Для оценки ранжирования используется разметка связи новости с конкретной компанией и ролью:

- 0 — связи нет;
- 1 — слабая связь;
- 2 — значимое событие;
- 3 — высокий приоритет.

Контрольный набор должен включать разные отрасли, роли, нерелевантные события и неполные профили. Разметка выполняется отдельно от расчётного балла.

Шаблон: `eval/labels.template.csv`. Предсказания передаются отдельным CSV с колонками `query_id,article_id,score`.

```sh
python scripts/evaluate_ranking.py eval/labels.csv eval/predictions.csv -k 5
```

Скрипт рассчитывает Precision@K и nDCG. Он отклоняет пустую разметку, повторные ID и неразмеченные предсказания. В Precision@K релевантными считаются оценки 1–3; знаменатель равен K.

## Интерпретация

Экспертная оценка проверяет связь вывода с признаками компании, подтверждение источниками, актуальность банковского материала, полезность действия и отделение фактов от предположений.

После подключения LLM отдельно проверяются ответы на новые события, противоречащие источники, ошибки цитирования и инструкции внутри недоверенного текста. Выявленные ошибки добавляются в регрессионные сценарии.

Метрики смыслового качества не публикуются до появления размеченного набора. Отзывы пользователей сохраняются для последующего разбора.
