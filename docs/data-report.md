В синтетическом наборе отдельно находятся три компании, две связи и два платежа. Профили обезличены; реальные названия организаций не восстанавливаются.

## Импорт

Файлы размещаются в `data/private`. Каталог исключён из Git и Docker-образа; в контейнер он монтируется для чтения.

```sh
python scripts/import_data.py --directory data/private --pdf
```

Для обработки только PDF используется `--only-pdf`. На Windows нужен Tesseract с языками `rus+eng`; в Docker он установлен.

Кодировка CSV определяется как UTF-8 или Windows-1251. Проверяются обязательные колонки, числовые значения, флаги и идентификаторы. Отчёт импорта хранится в `import_batches`, конфликты — в `data_issues`.

## Повторы и противоречия

- Неизменный файл пропускается по SHA-256 и версии импорта.
- Для противоречащих профилей сохраняется первое появление, альтернативы записываются в аудит.
- Различающиеся платёжные строки одной пары сохраняются отдельно; точные повторы удаляются.
- Ссылки на отсутствующие профили не отбрасываются и не дополняются вымышленными данными.
- Удаление строки из следующего файла не удаляет её из базы.

Платежи показываются как связи, а не как доказательство владения или зависимости. Период платежей и денежная единица в спецификации не определены, поэтому строки не используются для расчёта текущего долга или денежного эффекта новости.

## Документы и новости

Фрагменты PDF сохраняют ID документа, страницу, метод извлечения и ссылку на оригинал. Результат OCR нужно сверять с PDF. Число фрагментов может отличаться при другом способе распознавания.

RSS содержит заголовок, анонс, источник, ссылку и время публикации. Полный текст можно добавить отдельно. Повторы определяются по нормализованному заголовку и URL.

Лента рассматривает до 500 последних подходящих событий и возвращает до 100. Связи ограничены наиболее крупными строками и доступными групповыми связями. Эти ограничения вынесены в API и не означают полноту рыночной картины.
