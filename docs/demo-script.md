# Сценарий проверки

## Синтетический набор

1. Откройте приложение и выберите компанию DEMO_U_101.
2. Проверьте профиль, продукты и связи.
3. В ленте откройте событие о ставке. Посмотрите основания релевантности, последствия и действия.
4. Откройте «Источники» и «Как выполнен анализ».
5. Выберите DEMO_U_202 и сравните разбор того же события.
6. Добавьте новую новость текстом. Заголовок должен содержать минимум 5 символов, текст — минимум 30.

Роли пользователя меняют приоритеты ленты. Ручной текст сохраняется с отметкой непроверенного источника.

## Официальный набор

После импорта откройте «Настройки стенда» и введите `ADMIN_TOKEN` из `.env`.

Выберите U_9250: в профиле есть кредитный и лизинговый продукты. Найдите архивное событие о ключевой ставке и откройте разбор. Проверьте фрагменты банковского документа, страницы и ссылки.

Затем выберите U_57706 и откройте то же событие. Депозитный контекст должен отразиться в оценке и выводах. Сумма задолженности и свободные остатки из признака продукта не следуют.

## Уточняющий вопрос

После подключения LLM задайте вопрос к разбору. Ответ должен опираться на найденные источники; их можно открыть рядом с ответом. Без API поле вопроса недоступно, а анализ по правилам продолжает работать.
