# Синтетические данные

Три компании с разными отраслями и банковскими продуктами, две связи и два платежа предназначены для сквозной проверки приложения. Они не описывают реальные организации.

При запуске с `DEMO_MODE=true` набор загружается автоматически. Идентификаторы синтетических компаний начинаются с `DEMO_`. Учебные новости отмечены в интерфейсе.

Выручка синтетических компаний задана в рублях; это не определяет единицу официального набора.
