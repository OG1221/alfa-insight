# Памятка для сдачи и защиты

## Открыть сайт

Дважды нажмите «Открыть Альфа Инсайт.command» в этой папке. Адрес: http://127.0.0.1:8000. Документация API: http://127.0.0.1:8000/api/docs.

По умолчанию видны три синтетических компании. Для официального набора: «Настройки стенда» → alfa-local-admin → «Открыть данные кейса». Это локальный демонстрационный токен, не банковский аккаунт. Официальные данные уже импортированы на этой машине.

На другом компьютере: README → Docker Compose. Официальные материалы в ZIP/Git не включены; получить их из папок организаторов и импортировать по README.

## Показать за 3–5 минут

1. Обзор и сформированный профиль. Честно назвать текущий режим «анализ по правилам».
2. Выбрать U_9250, найти «Архив · 11 сентября 2026»: кредитный контекст, риск плавающей ставки только при подходящих условиях, неопределённость задолженности.
3. Открыть источники, страницы банка и фактические действия агента.
4. Для U_57706 открыть то же событие: депозитный контекст, другое обоснование и оценка.
5. Добавить новую учебную новость, показать её сохранение, разбор и источники.
6. Кратко показать метрики и ограничения AI. Подробный текст: docs/demo-script.md.

## Что зависит от организаторов

Настоящая LLM и уточняющий диалог требуют разрешённого API, который пока не выдан. Адаптер и тесты готовы, реальных LLM-вызовов не было. После получения реквизитов: docs/llm-setup.md. Не представлять правила как генерацию модели и не заявлять полное закрытие AI-критериев до этой проверки.
